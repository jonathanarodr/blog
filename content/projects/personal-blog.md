## Visão Geral

Este blog pessoal foi construído com Hugo e o tema Hextra para compartilhar artigos técnicos, projetos e reflexões sobre desenvolvimento de software.

## Recursos

- **Design Moderno**: Interface limpa e responsiva com Tailwind CSS
- **Modo Escuro**: Suporte completo a tema claro/escuro/sistema
- **Busca**: Busca de texto completo integrada
- **Syntax Highlighting**: Destaque de código para múltiplas linguagens
- **Deploy Automático**: CI/CD com GitHub Actions

## Tecnologias

- **Hugo** - Gerador de sites estáticos
- **Hextra Theme** - Tema moderno para Hugo
- **Tailwind CSS** - Framework CSS utility-first
- **GitHub Pages** - Hospedagem estática
- **GitHub Actions** - Pipeline de deploy automatizado

## Características Técnicas

### Performance

- Build em segundos
- Site totalmente estático
- Sem JavaScript necessário para funcionalidades básicas
- Otimizado para SEO

### Desenvolvimento

- Hot reload durante desenvolvimento
- Markdown para escrita de conteúdo
- Git para versionamento
- Deploy automático em cada push
